# 🛡️ FocusNest — Bảo vệ & Đồng hành học tập trên MacBook

Trang web hướng dẫn và bộ cài đặt chính thức cho phụ huynh:

- 🌐 **Trang hướng dẫn cài đặt:** https://tuanvl.github.io/focusnest/
- ⚡ **Cài nhanh (macOS Apple Silicon & Intel):**
  ```bash
  /bin/bash -c "$(curl -fsSL https://tuanvl.github.io/focusnest/install.sh)"
  ```
- 🧹 **Gỡ cài đặt & khôi phục Wi-Fi mặc định:**
  ```bash
  /bin/bash -c "$(curl -fsSL https://tuanvl.github.io/focusnest/uninstall.sh)"
  ```
- 📦 **Bản tải `.dmg` & SHA-256 Checksums:** Xem tại mục [Releases](https://github.com/tuanvl/focusnest/releases/latest).
